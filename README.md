# Paula Riquelme portfolio

English-only professional portfolio for Paula Riquelme, Product Lead, Product Designer, and Frontend Developer.

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run validate:architecture
npm run validate:agent-docs
npm run test
npm run coverage
npm run lint
npm run typecheck
npm run build
npm run test:e2e
```

## Production

The site is statically exported to `out` and deployed through the official GitHub Pages Actions workflow at:

https://PauRiquelmee.github.io/paula-riquelme-portfolio/

See `docs/architecture.md` for system boundaries, accessibility, SEO, testing, assets, and deployment decisions.
