# Design system

## Direction

The portfolio behaves like a product launch dossier assembled by someone who can move from field evidence to interface detail and shipped code. It uses editorial rhythm without resembling a magazine template. The signature is a compressed typographic register paired with an evidence ledger that makes Paula's outcomes visible in the first viewport.

## Visual world

- Color strategy: restrained warm white, near-black, and one deep indigo.
- Background: `#f3f0e8`.
- Text: `#11110f`.
- Accent: `#4338a8`.
- Muted text: `#68665f`.
- Lines: `rgba(17, 17, 15, 0.22)`.
- Display type: condensed grotesk with forceful, narrow silhouettes.
- Body type: calm humanist sans with open counters.
- Metadata: small uppercase labels with measured tracking, not decorative mono filler.
- Geometry: square corners, thin rules, inset gutters, offset columns, and occasional vertical text.
- Elevation: no card shadows. Overlays use a restrained page-like shadow only when they detach from the document.

## Composition

The desktop page uses a twelve-column editorial grid. The first viewport includes the sticky masthead, a slim role register, the large headline, supporting copy, two actions, and a proof ledger showing 50+ customers, three countries, and USD 70K in funding. The PR monogram acts as an anchoring mark, not a decorative logo tile.

Selected work alternates dense evidence with large factual media. Experience reads as a structured index, not a decorative timeline. Recognition and press use underlined editorial links with supplied images. The contact close returns to oversized type and one direct conversation prompt.

## Interaction and motion

- One restrained opening sequence for the first viewport.
- Project media reveals with a short opacity and small vertical transition.
- Base UI dialogs feel like opening a working proof sheet above the page.
- Mobile navigation uses a compact Base UI dialog with a short slide and fade.
- Focus indicators use a two-pixel indigo outline with offset.
- Reduced motion removes spatial transitions and preserves immediate opacity feedback.

## Responsive behavior

At tablet width the evidence ledger becomes a three-column band and the headline keeps an intentionally uneven line break. On mobile the vertical register becomes a horizontal label, navigation collapses, the headline remains large but readable, and media stacks above proof. Project previews favor the screenshot and external link when an iframe would reduce usability.

## Imagery

Only factual user-supplied media and deterministic identity assets ship. No personal portrait, stock illustration, generated decoration, or generic device mockup is used. Crops retain enough publication context to remain honest.

## Accessibility

The design preserves semantic order independent of visual offsets, WCAG AA contrast, visible focus, 44 pixel interactive targets, resilient text reflow, descriptive media alternatives, and a fully operable keyboard path.
